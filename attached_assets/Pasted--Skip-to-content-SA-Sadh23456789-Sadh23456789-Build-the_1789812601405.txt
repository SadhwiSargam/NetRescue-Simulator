PROJECT TITLE
NetRescue — Network Resilience and Automatic Failure Recovery Simulator

Alternative title if needed:

Network Resilience Simulator

CORE IDEA
The project is a software-based simulation system that demonstrates how a computer network can recover when a communication link or network node fails.

The system creates a virtual network represented as a graph.

The user selects or generates a source and destination.

The application calculates the current route.

The user can simulate a network failure, such as:

link failure
node failure
The system detects whether the current route has been broken.

If the destination is still reachable, the system calculates an alternative route and displays the recovery.

The system must also support automatically generated simulation scenarios so that hundreds or thousands of experiments can be run without manually collecting external data.

The project is a SIMULATION.

It does not interact with or modify real computer networks.

PRIMARY REAL-WORLD PROBLEM
Real networks can experience failures.

If a communication link or network device fails, the current path between two endpoints may become unavailable.

Networks can maintain resilience by having alternative paths.

This project demonstrates this concept computationally by:

creating a virtual network,
creating routes,
introducing failures,
detecting broken routes,
finding alternative routes,
measuring recovery.
